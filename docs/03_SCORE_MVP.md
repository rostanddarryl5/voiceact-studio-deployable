# Criteres de score MVP

## Principe

Le score VoiceAct ne doit pas pretendre mesurer parfaitement l'emotion ou le talent.

Il combine :
- des mesures objectives ;
- une interpretation de coaching ;
- une comparaison avec l'objectif de l'exercice.

## Score global

Score sur 100 :
- technique : 55 points ;
- intention : 30 points ;
- progression : 15 points.

## Score technique - 55 points

### Debit - 15 points

Mesure :
mots par minute.

Evaluation :
- trop lent ;
- adapte ;
- trop rapide.

Le debit cible depend du contexte :
- horreur : plus lent ;
- actualite : plus direct ;
- divertissement : plus dynamique ;
- histoire : pose ;
- motivation : progressif.

### Pauses - 15 points

Mesure :
silences et respirations detectables.

Evaluation :
- aucune pause forte ;
- pauses trop longues ;
- pauses bien placees ;
- rythme hache.

### Energie - 15 points

Mesure :
volume moyen et variation d'amplitude.

Evaluation :
- voix plate ;
- energie stable ;
- variation utile ;
- surintensite.

### Clarte - 10 points

Mesure :
comparaison entre texte attendu et transcription.

Evaluation :
- mots manques ;
- diction confuse ;
- texte clair ;
- rythme qui mange les mots.

## Score intention - 30 points

Ce score est formule comme coaching.

Il evalue si la prise semble compatible avec :
- le theme ;
- le moment ;
- l'emotion attendue ;
- la direction vocale.

Exemples :
- hook horreur : tension, lenteur, pause avant revelation ;
- corps actualite : precision, regularite, credibilite ;
- conclusion motivation : montee, conviction, phrase finale forte ;
- doublage menace calme : controle, lenteur, intensite basse.

## Score progression - 15 points

Compare la prise actuelle a la prise precedente du meme exercice.

Mesure :
- meilleur respect de la duree cible ;
- debit plus adapte ;
- pauses plus nettes ;
- variation d'energie plus lisible ;
- reduction des mots parasites ;
- feedback IA plus positif.

## Sortie d'analyse attendue

Chaque analyse doit retourner :
- score global ;
- score debit ;
- score pauses ;
- score energie ;
- score clarte ;
- score intention ;
- conseil principal ;
- phrase a refaire ;
- objectif de la prochaine prise.

## Regle de langage

Ne jamais dire :
"Ton emotion est mauvaise."

Dire plutot :
"L'intention demandee n'est pas encore assez lisible. Pour cette prise, ralentis le debut et baisse legerement l'energie avant la revelation."
