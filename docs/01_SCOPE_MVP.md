# Etape 1 - Scope MVP 30 jours

## Decision produit

Le MVP s'appelle VoiceAct Studio.

Il cible deux usages seulement :
- voix off pour createurs video ;
- doublage cinema court.

Le produit n'apprend pas au createur a structurer une video. Il l'aide a interpreter vocalement une structure deja connue : hook, corps, conclusion.

## Promesse

Transformer une voix off plate en narration plus percutante, adaptee au theme, au moment de la video et a l'emotion recherchee.

## Cible de depart

### Createur video

Createur solo qui fait des videos courtes ou longues avec voix off :
- YouTube ;
- TikTok ;
- Reels ;
- documentaires courts ;
- storytelling ;
- horreur/mystere ;
- actualite ;
- motivation.

Probleme principal :
la voix off est souvent monotone, trop rapide, mal placee, ou pas adaptee a l'emotion du sujet.

### Doubleur cinema debutant

Personne qui veut s'entrainer a jouer une replique avec intention :
- emotion claire ;
- rythme ;
- diction ;
- intensite ;
- naturel.

Probleme principal :
la voix sonne lue, forcee ou plate.

## Fonctionnalites incluses

- choix du profil : createur video ou doubleur cinema ;
- choix du theme ou de la scene ;
- texte d'exercice ;
- direction vocale ;
- enregistrement micro dans le navigateur ;
- lecture de la prise ;
- analyse de base ;
- feedback IA contextuel ;
- comparaison entre deux prises ;
- historique simple ;
- limite d'analyses ;
- plan gratuit ;
- plan payant simple.

## Fonctionnalites exclues

- application mobile native ;
- reseau social ;
- marketplace de voix ;
- battle avance ;
- classement public ;
- PDF automatique ;
- analyse emotionnelle presentee comme certitude scientifique ;
- clonage vocal ;
- references audio de celebrites ;
- import video complet ;
- synchronisation labiale avancee ;
- edition audio avancee ;
- multi-langue complete.

## Metriques vocales MVP

Le MVP mesure uniquement ce qu'il peut mesurer de maniere raisonnable :
- duree de la prise ;
- mots par minute ;
- pauses ;
- volume moyen ;
- variation d'energie ;
- variation de rythme ;
- mots parasites ;
- ecart avec la duree cible ;
- clarte via transcription.

Le feedback emotionnel est formule comme coaching, pas comme diagnostic absolu.

## Parcours utilisateur MVP

1. L'utilisateur arrive sur VoiceAct Studio.
2. Il choisit "Createur video" ou "Doubleur cinema".
3. Il choisit un exercice.
4. Il lit la direction vocale.
5. Il enregistre sa prise.
6. Il ecoute sa prise.
7. Il lance l'analyse.
8. Il recoit un score et un conseil actionnable.
9. Il refait une prise.
10. Il compare la progression.

## Critere de reussite produit

Le MVP est considere fonctionnel si un utilisateur peut :
- choisir un exercice ;
- enregistrer sa voix ;
- ecouter sa prise ;
- recevoir un feedback utile ;
- refaire une prise ;
- comprendre quoi ameliorer ;
- voir une difference entre deux essais.

## Critere de reussite marche

La beta est validee si :
- 30 personnes testent le produit ;
- 10 personnes font au moins 3 sessions ;
- 5 personnes acceptent de payer ou de precommander ;
- 3 personnes donnent un temoignage clair sur l'utilite du feedback.

## Contraintes 30 jours

Chaque fonctionnalite doit respecter une regle :

Si elle ne rend pas la premiere session vocale meilleure ou plus vendable, elle attend la V2.
