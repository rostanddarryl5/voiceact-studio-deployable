# Prosodie, pauses et intonation

## Definition utile pour VoiceAct

La prosodie regroupe les elements de la parole qui depassent les mots :
- intonation ;
- rythme ;
- accentuation ;
- pauses ;
- volume ;
- duree ;
- qualite vocale ;
- energie.

Pour VoiceAct, la prosodie est le coeur du produit. Deux personnes peuvent lire le meme texte, mais produire une emotion completement differente selon :
- ou elles ralentissent ;
- ou elles respirent ;
- quel mot elles accentuent ;
- si la voix monte ou descend ;
- si l'energie est stable, contenue ou explosive.

## Principes pedagogiques

### 1. Decouper le texte en groupes de sens

Un apprenant ne doit pas lire un paragraphe entier comme un bloc.

VoiceAct doit segmenter le texte en petites unites :
- phrase ;
- demi-phrase ;
- expression cle ;
- mot d'impact.

Chaque unite peut recevoir :
- une pause avant ;
- une pause apres ;
- une intention ;
- une forme d'intonation.

### 2. Les pauses portent le sens

Une pause n'est pas seulement une respiration.

Elle peut servir a :
- creer une attente ;
- laisser une image mentale ;
- separer deux idees ;
- augmenter la tension ;
- donner de la gravite ;
- rendre une chute plus forte.

Dans VoiceAct, chaque pause doit etre expliquee comme une action expressive :

Mauvais :
"Pause 500 ms."

Bon :
"Pause courte : laisse l'auditeur imaginer la maison avant la revelation."

### 3. L'intonation doit etre visible simplement

La courbe d'intonation ne doit pas ressembler a un outil d'ingenieur son.

Elle doit utiliser des formes pedagogiques :
- montee ;
- descente ;
- plateau ;
- creux ;
- attaque forte ;
- chute froide ;
- suspension.

Exemple :

Horreur hook :
- debut bas ;
- montee tres legere ;
- pause ;
- chute froide sur la revelation.

Actualite hook :
- attaque nette ;
- plateau stable ;
- petite montee sur l'enjeu ;
- conclusion ferme.

Motivation conclusion :
- montee progressive ;
- accent fort sur le mot d'action ;
- fin haute mais controlee.

## Metriques utiles

VoiceAct peut mesurer localement :
- duree totale ;
- volume moyen ;
- pic audio ;
- variation d'energie ;
- pourcentage de silence ;
- nombre de pauses ;
- debit estime.

Avec transcription, VoiceAct pourra mesurer :
- mots par minute reels ;
- mots parasites ;
- respect du texte ;
- mots avales ;
- placement des pauses par rapport aux phrases.

Avec analyse de pitch, VoiceAct pourra mesurer :
- montee/descente d'intonation ;
- variation de frequence fondamentale ;
- monotonie approximative ;
- accentuation relative.

## Limite importante

VoiceAct ne doit pas pretendre savoir parfaitement si une emotion est "vraie".

Le logiciel doit dire :
"L'intention demandee est plus ou moins lisible selon les indices vocaux."

Et non :
"Tu es triste a 82%."
