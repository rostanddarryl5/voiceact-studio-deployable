# Mobile-first UX VoiceAct

## Decision

VoiceAct Studio doit etre pense mobile d'abord.

Le mobile n'est pas une version reduite du desktop. C'est l'experience principale :
- tenir le telephone ;
- lire un texte court ;
- enregistrer une prise ;
- recevoir un retour immediat ;
- refaire une prise ;
- progresser par petites sessions.

## Contraintes UX

- Une session doit pouvoir durer 3 a 7 minutes.
- Le bouton d'enregistrement doit etre large, stable et toujours visible.
- Le texte a lire doit etre tres lisible, avec segmentation phrase par phrase.
- Les pauses doivent etre guidees visuellement.
- L'intonation cible doit etre visible sans demander de competence musicale.
- Le feedback doit tenir en quelques cartes actionnables.
- L'utilisateur ne doit jamais se demander quoi faire ensuite.

## Ecran Studio mobile cible

Ordre ideal :

1. Contexte de l'exercice.
2. Objectif vocal.
3. Texte segmente.
4. Metronome de pauses.
5. Courbe d'intonation simplifiee.
6. Bouton enregistrer.
7. Barre niveau micro.
8. Lecture de la prise.
9. Score.
10. Conseil unique de reprise.

## Regle d'or

Sur mobile, un feedback long est un mauvais feedback.

VoiceAct doit donner :
- 1 score global ;
- 3 sous-scores maximum ;
- 1 conseil principal ;
- 1 objectif pour la prochaine prise.
