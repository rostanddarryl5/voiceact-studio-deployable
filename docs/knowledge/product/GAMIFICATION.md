# Gamification VoiceAct

## Principe

La gamification de VoiceAct doit renforcer l'apprentissage, pas decorer l'interface.

Les elements prioritaires :
- progression visible ;
- feedback immediat ;
- objectifs courts ;
- sentiment de competence ;
- niveaux de maitrise ;
- defis de reprise ;
- badges pedagogiques.

## Ce qu'il faut eviter

- leaderboard global au lancement ;
- competition toxique ;
- badges sans rapport avec la competence ;
- trop d'animations ;
- score humiliant ;
- feedback qui ressemble a une note scolaire.

## Boucle de jeu principale

1. Choisir une mission vocale.
2. Lire la direction.
3. Enregistrer une prise.
4. Recevoir un feedback.
5. Refaire une prise avec un objectif precis.
6. Voir l'amelioration.
7. Gagner de l'XP liee a la competence travaillee.

## Types d'XP

XP globale :
- recompense l'assiduite.

XP technique :
- rythme ;
- pauses ;
- articulation ;
- energie.

XP interpretation :
- tension ;
- gravite ;
- conviction ;
- naturel ;
- contraste emotionnel.

## Badges utiles

- Premier Hook : premiere prise terminee.
- Reprise Propre : deuxieme prise meilleure que la premiere.
- Silence Maitre : pauses mieux placees.
- Voix Stable : volume plus controle.
- Anti Monotonie : variation d'energie amelioree.
- Chute Finale : conclusion mieux marquee.
- Tension Froide : exercice horreur reussi.
- Voix Credible : exercice actualite reussi.

## Niveaux

Niveau 1 : Decouverte
- comprendre la consigne ;
- faire une prise.

Niveau 2 : Controle
- corriger le debit ;
- placer des pauses.

Niveau 3 : Intention
- adapter l'energie au domaine ;
- faire entendre l'emotion.

Niveau 4 : Interpretation
- gerer contraste, silences et chute.

Niveau 5 : Signature
- developper un style vocal reconnaissable.
