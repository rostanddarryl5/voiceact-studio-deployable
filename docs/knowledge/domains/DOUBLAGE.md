# Doublage cinema - principes MVP

## Objectif VoiceAct

Le doublage dans VoiceAct n'est pas encore du lip-sync professionnel complet.

Le MVP vise :
- intention claire ;
- rythme adapte ;
- pause expressive ;
- naturel ;
- coherence emotionnelle ;
- duree approximative.

## Concepts importants

### Isochronie

Dans le doublage, la duree de la replique cible doit souvent rester proche de la duree originale pour conserver la coherence audiovisuelle.

Pour VoiceAct :
- afficher une duree cible ;
- signaler si la prise est trop courte ou trop longue ;
- guider le rythme avant de chercher la performance.

### Alignement prosodique

La replique doit respecter une structure :
- groupes de sens ;
- pauses ;
- accents ;
- montees/descentes d'intonation ;
- attaques et fins de phrases.

Pour VoiceAct :
- chaque replique doit etre segmentee ;
- chaque segment a une intention ;
- chaque pause a une fonction expressive.

### Intention avant intensite

Les debutants confondent souvent emotion et volume.

VoiceAct doit corriger :
- trop crie ;
- trop plat ;
- pas assez retenu ;
- rupture emotionnelle trop brutale ;
- diction qui devient floue.

## Exercices prioritaires

- peur silencieuse ;
- colere contenue ;
- tristesse retenue ;
- menace calme ;
- confidence ;
- surprise ;
- joie naturelle ;
- tension dramatique ;
- replique de heros ;
- replique de mechant.

## Feedback pedagogique

Mauvais :
"Tu n'es pas assez triste."

Bon :
"La tristesse doit etre plus retenue. Ralentis la deuxieme phrase, baisse l'energie, puis laisse une pause apres 'plus de temps'."
