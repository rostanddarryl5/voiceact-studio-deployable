# Nouvelles exigences produit - VoiceAct Studio

## Orientation majeure

VoiceAct Studio doit etre developpe mobile-first.

Le desktop sert au developpement et aux tests, mais l'experience principale vise :
- smartphone ;
- lecture courte ;
- enregistrement rapide ;
- feedback immediat ;
- reprise de prise ;
- progression gamifiee.

## Exigence 1 - Studio mobile-first

L'interface doit etre repensee pour mobile :
- controles grands ;
- texte tres lisible ;
- enregistrement accessible au pouce ;
- etapes verticales ;
- aucun panneau lateral obligatoire ;
- feedback court ;
- progression visible.

Critere :
un utilisateur doit pouvoir faire une session complete avec une seule main.

## Exigence 2 - Gamification pedagogique

VoiceAct doit integrer :
- XP ;
- niveaux ;
- missions ;
- streak ;
- badges pedagogiques ;
- progression par competence ;
- defis de reprise.

La gamification ne doit jamais remplacer le feedback vocal.

Elle doit encourager :
- refaire une prise ;
- corriger un point precis ;
- travailler plusieurs styles ;
- developper une signature vocale.

## Exigence 3 - Metronome expressif

Chaque exercice doit afficher un guide de pauses.

Le guide indique :
- pause courte ;
- pause moyenne ;
- pause longue ;
- mot a accentuer ;
- moment de reprise.

Ce metronome doit varier selon le domaine :
- horreur : pauses plus longues, tension, chute froide ;
- actualite : pauses courtes, rythme direct ;
- histoire : pauses posees, gravite ;
- motivation : montee progressive ;
- divertissement : rythme vivant ;
- doublage : pauses liees a l'intention de scene.

## Exigence 4 - Courbe d'intonation cible

Chaque texte doit afficher une courbe simple :
- monter ;
- descendre ;
- rester bas ;
- rester stable ;
- construire ;
- chute finale.

Cette courbe est pedagogique, pas musicale.

Elle doit aider l'apprenant a comprendre :
- ou mettre la tension ;
- ou calmer la voix ;
- ou faire monter l'energie ;
- ou conclure.

## Exigence 5 - Analyse apres prise

L'analyse doit comparer :
- ce qui etait attendu ;
- ce que l'utilisateur a produit ;
- la prochaine correction a faire.

MVP actuel :
- duree ;
- debit estime ;
- volume ;
- pic ;
- silence ;
- pauses ;
- variation d'energie.

Prochaine evolution :
- transcription ;
- correspondance texte lu ;
- pauses par segment ;
- pitch approximatif ;
- comparaison avec courbe cible.

## Exigence 6 - Base de connaissance

Chaque domaine doit avoir une fiche :
- objectif emotionnel ;
- rythme cible ;
- type de pauses ;
- courbe d'intonation typique ;
- erreurs frequentes ;
- conseils de reprise ;
- exemples d'exercices.

Domaines prioritaires :
- horreur / mystere ;
- histoire / documentaire ;
- actualite / news ;
- motivation / storytelling ;
- divertissement / YouTube ;
- doublage cinema.
